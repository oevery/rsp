# 设备发现边界

## 当前架构

- 桌面运行时负责物理设备发现及连接生命周期。
- 运行时中立包 `client/packages/device-discovery` 只投影设备事件：`projectDeviceEvent` 将原始 `{ id, connected }` 记录规范化为不可变的类型化记录，不执行设备、桌面或浏览器 I/O。
- Web 只消费投影后的类型化值，不直接发现硬件，也不导入或调用硬件适配器。

## 验收边界

- 接收器硬件验收目前不可用，且由人工负责。
- 自动化测试覆盖纯投影的规范化、拒绝空设备标识和不可变性；自动化测试不是硬件验收。
- 本边界不将纯投影函数或自动化测试视为桌面到 Web 的生产调用链已经接入的证据。
