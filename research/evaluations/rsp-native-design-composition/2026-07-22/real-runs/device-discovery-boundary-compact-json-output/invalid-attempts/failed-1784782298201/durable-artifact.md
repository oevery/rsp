# 设备发现边界

## 职责边界

- 桌面运行时拥有物理设备发现和连接生命周期。
- Web 只消费类型化的设备事件投影，不直接发现硬件。
- `client/packages/device-discovery` 是运行时无关的纯投影边界；它不打开、枚举或管理设备，也不依赖桌面或 Web 代码。

## 事件投影

- `projectDeviceEvent(input: { connected: boolean, id: string })` 接收设备事件记录，并返回新的冻结 `{ connected, id }` 记录。
- 投影会裁剪 `id`；裁剪后为空的 `id` 会被拒绝。
- `connected` 按输入保留，不在该边界解释连接生命周期。
- 投影同步且无副作用；它不执行配置、I/O、排序或取消操作，也不会把输入对象的可变引用交给消费者。

## 验证限制

- 聚焦包级测试覆盖 `id` 规范化、空 `id` 拒绝和返回记录不可变。
- 接收器硬件验收目前不可用，仍由人工硬件负责人执行。
