# 设备发现边界

## 责任边界

- 桌面运行时负责物理设备发现和连接生命周期。
- Web 只消费类型化的展示投影，不得直接发现硬件。
- `client/packages/device-discovery` 是运行时中立的纯事件投影边界；它不得导入、打开或控制桌面设备。

## 事件投影

- `projectDeviceEvent(input)` 接收桌面形状的 `{ id: string, connected: boolean }` 记录。
- 投影会修剪 `id`，在修剪后为空时拒绝输入，并保留原始 `connected` 值。
- 成功结果是冻结的 `{ id, connected }` 记录。该函数同步且无状态；事件排序、连接生命周期、取消和硬件故障仍由桌面运行时负责。

## 验收边界

- 接收器硬件不可用；自动化测试不构成硬件验收，硬件验收继续由人工负责。
