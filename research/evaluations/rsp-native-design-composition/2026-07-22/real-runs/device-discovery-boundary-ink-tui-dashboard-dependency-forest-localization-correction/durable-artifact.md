# 设备发现边界

## 职责与依赖

- 桌面运行时拥有物理设备发现和连接生命周期。
- `client/packages/device-discovery` 是运行时中立的边界，只负责将桌面适配器提供的原始 `{ id, connected }` 记录投影为类型化事件。
- Web 只能消费投影后的事件；不得依赖桌面适配器、直接发现硬件或打开设备。
- 运行时中立包不得依赖桌面、Web、接收器 API 或连接生命周期状态。

## 投影契约

- `projectDeviceEvent` 接收一个原始 `{ id, connected }` 记录，修剪 `id`，拒绝修剪后为空的值，并返回冻结的 `{ id, connected }` 投影。
- 该边界是无状态的：不发现设备、不保存连接状态、不重试，也不转换接收器传输失败。

## 验证边界

- 接收器硬件验收仍不可用，且属于人工负责的独立检查。
- 自动化测试只验证投影契约；它们不是硬件验收，不能替代真实接收器的验收结果。
