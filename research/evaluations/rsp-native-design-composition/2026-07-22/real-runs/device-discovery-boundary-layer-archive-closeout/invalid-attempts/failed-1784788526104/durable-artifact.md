# 设备发现边界

## 职责

- `client/packages/device-discovery` 提供运行时中立的单条设备事件投影。
- 桌面适配器拥有物理设备发现和连接生命周期；Web 仅消费类型化的展示投影。

## 公开边界

- 包入口导出 `projectDeviceEvent(input)`，输入为原始 `{ id, connected }` 记录。
- 投影会去除 `id` 两端空白、拒绝空的结果、保留 `connected`，并返回新的冻结 `{ id, connected }` 记录。

## 依赖约束

- 依赖方向为桌面适配器 -> `device-discovery` 投影器 -> 类型化展示消费者。
- 该包不得导入桌面运行时或 Web 模块，不得打开设备、订阅硬件事件或保存连接状态。

## 验证边界

- 单元测试覆盖公开投影器的规范化、空 `id` 拒绝和不可变结果。
- 接收器硬件验收仍不可用，且不由自动化测试覆盖。
