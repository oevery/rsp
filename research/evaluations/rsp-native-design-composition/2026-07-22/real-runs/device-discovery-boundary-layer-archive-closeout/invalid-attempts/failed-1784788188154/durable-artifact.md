# 设备发现边界

## 职责边界

- 桌面运行时是物理设备发现、接收器打开和连接生命周期的唯一所有者。
- Web 只消费已投影的设备事件，不直接发现或打开硬件。
- `client/packages/device-discovery` 提供运行时中立的设备事件投影；该包不依赖桌面或 Web 模块，也不打开或发现物理设备。

## 事件投影契约

- `projectDeviceEvent(input)` 接受 `{ id: string, connected: boolean }`，并返回只读的 `{ id, connected }` 事件记录。
- 投影会修剪 `id`；修剪后为空的 ID 会被拒绝。
- 返回的事件记录是新的冻结对象，`connected` 保持输入值不变。

## 验证边界

- 聚焦自动化测试验证 ID 归一化、空 ID 拒绝和返回记录不可变。
- 接收器硬件验收由人工负责，当前不可用；自动化测试不构成硬件验收。
