# 设备发现边界

## 所有权

- 桌面运行时负责物理设备发现、连接生命周期，以及原始 `{ id, connected }` 记录的发出。
- Web 仅消费类型化的展示投影，不直接发现硬件。
- 运行时中立的 `client/packages/device-discovery` 只负责纯事件投影；它不得导入、打开或依赖桌面或接收器 API。

## 投影契约

- 桌面适配器将每条原始记录传入 `projectDeviceEvent`，展示消费者只接收其返回值。
- `projectDeviceEvent` 会去除 `id` 两端空白；规范化后为空的 `id` 会被拒绝。
- 返回的 `{ id, connected }` 投影为冻结的只读记录，并保留布尔连接状态。
- 该包不拥有设备状态、订阅、顺序、重试或生命周期策略。

## 验收边界

- 接收器硬件不可用；物理发现链路的硬件验收仍由人工负责，当前不可用。
