# 设备发现边界

## 职责边界

- 桌面运行时拥有物理接收器的发现和连接生命周期。
- Web 仅消费设备事件的展示投影，不直接发现硬件。
- `client/packages/device-discovery` 是运行时中立的事件投影边界；它不得依赖桌面运行时 API、Web API 或打开设备的能力。

## 事件投影

- `projectDeviceEvent(input: { id: string, connected: boolean })` 接收一个桌面来源的原始记录，并返回冻结的 `{ id, connected }` 投影。
- 投影会修剪 `id`；修剪后为空的设备标识必须被拒绝。
- 此边界是同步且无状态的：不负责发现、连接、排序、取消或配置。

## 验证边界

- 聚焦单元测试覆盖标识规范化、空标识拒绝和返回值不可变性。
- 接收器硬件验收不可用，仍由人工负责；自动化测试不构成硬件验收。
