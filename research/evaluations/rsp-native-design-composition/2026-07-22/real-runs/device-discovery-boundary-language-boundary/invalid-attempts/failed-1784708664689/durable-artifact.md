# 设备发现边界

## 职责

- 桌面运行时拥有物理设备发现和连接生命周期，并产生原始 `{ id, connected }` 记录。
- `client/packages/device-discovery` 拥有对该记录的纯、运行时中立投影；该包不枚举设备、不执行连接生命周期、不进行 IPC，也不持有 Web 展示状态。
- Web 只能消费投影后的类型化记录，不能导入硬件适配器或主动发起设备发现。

## 公共边界

- `projectDeviceEvent(input)` 是 runtime-neutral 包的公共入口。
- 它会将 `id` 去除首尾空白，拒绝去除空白后为空的 id，并返回冻结的 `{ id, connected }` 记录。
- `connected` 按输入原样保留；该投影不承载生命周期策略、事件排序、配置或硬件 I/O。

## 验收约束

- 聚焦单元测试覆盖公共入口的规范化、结果不可变性和空 id 拒绝。
- 接收器硬件验收仍不可用，且由人工负责；自动化测试不构成硬件验收通过。
