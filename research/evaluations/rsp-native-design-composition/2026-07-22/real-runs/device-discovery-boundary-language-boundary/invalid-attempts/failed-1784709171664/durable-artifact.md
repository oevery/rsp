# 设备发现边界

## 运行时所有权

- Desktop runtime 负责物理设备发现和连接生命周期。
- Web 仅消费已投影的类型化设备事件作为展示数据，不直接发现硬件，也不依赖桌面适配器。

## 运行时中立投影

- `client/packages/device-discovery` 提供运行时中立的同步事件投影，不导入运行时 API，也不打开设备。
- 其公共入口 `projectDeviceEvent(input)` 接收 `{ id, connected }`，修剪 `id`，并在结果为空时同步抛出设备 ID 校验错误。
- 成功时，该函数返回新的冻结只读 `{ id, connected }` 投影；它不负责 I/O、配置、生命周期、排序、取消或重试。

## 验收约束

- 接收器硬件当前不可用；自动化测试不能替代硬件验收。
