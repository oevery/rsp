# 设备发现边界

## 职责

- 桌面运行时拥有物理设备发现与连接生命周期，并产生原始 `{ id, connected }` 事件。
- `client/packages/device-discovery` 提供运行时中立的 `projectDeviceEvent(input)` 投影；该包不打开设备，也不拥有连接生命周期。
- Web 仅消费已经投影的类型化记录，不直接发起硬件发现。

## 边界契约

- `projectDeviceEvent` 接受 `{ id, connected }`，修剪 `id`，并拒绝修剪后为空的标识符。
- 投影保留 `connected`，返回一个新的冻结记录。
- 排序、取消、配置、重试与设备状态策略仍由桌面生命周期所有者负责，不属于投影边界。

## 依赖方向

- 桌面运行时可以依赖运行时中立的投影包；投影包不得依赖桌面运行时或 Web。
- 后续运行时接入必须在桌面到消费者的边界调用该投影，且不得将物理发现迁入投影包或 Web。

## 验收限制

- 接收器硬件不可用；硬件验收仍由人工负责，当前不可用。
