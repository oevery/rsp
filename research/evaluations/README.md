# Evaluation conclusions

These reports preserve historical findings, including failed and inconclusive outcomes. They are not current release gates or proof of current model quality. Per-run metadata, scores and compact experiment summaries retain the minimum context needed to interpret them.

Raw events, phased messages, duplicated input trees and old runners referenced by a report may require selected private evidence or fixed-history Git recovery; disposable runtime material is no longer retained. See [historical artifact recovery](../ARCHIVE-RECOVERY.md) for the exact path/disposition mapping and recovery limits. Do not rewrite immutable reports to hide missing local evidence or change their verdicts.

Current executable cases and the shared executor/judge configuration live under `tests/skills/`; new raw execution reports stay ignored under `tests/skills/reports/`.
