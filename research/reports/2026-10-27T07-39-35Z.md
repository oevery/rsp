The two user-selected analyses support a bounded RSP simplification, not wholesale adoption of another workflow. Local source is RSP `f686ca6aa7c2285097a51f2129c1a91909bff0a0`, initially clean. This report selects the recommendations used by `lean-behavior-boundaries`; it records no model experiment.

[Release notes](https://github.com/obra/superpowers/releases/tag/v7.0.1), read October 27, describe conditional references mitigating a Claude Code truncation limit. Reference count alone is therefore not a sensible optimization objective.

- DeepSeek Harness commit `22ddee3792402c3e70ec5f86a63c3e3e895a2f60`, `docs/testing.md`: real internal composition, shipped entry paths and external effects rather than agent self-report. Do not adopt its per-file 100% coverage or paid-test policy.

These are model-only recommendations, independently expressed for RSP; no upstream code or prose asset is copied. No adaptation or relicensing claim is made. Community reports identify risks, not measured RSP failure rates.

## Local applicability

The existing Implement and assessment contracts already reject private-structure tests, duplicate confidence and gratuitous permanent probes. Strengthen their default selection rather than adding a second testing policy. Keep contextual unit tests, real security/protocol assertions and public defaults.

Review's defect gate and “code reduction is never the objective” can discourage safe simplification findings. Distinguish demonstrated failures from smaller alternatives that preserve responsibility. Doc should separate equivalent wording edits from authorized retirement of instructions; correctness alone does not justify keeping every instruction.

At the inspected baseline, Verify required a comparison baseline and two diagnostic fields for every result. Current-target checks need a target, not necessarily an old revision or machine protocol. Existing research capture already avoids a parallel digest identity. Trusted external digests, content-bound security suppressions, exact Git delivery and destructive recovery remain different responsibilities.

The initial scanner found seven product entrypoints with 8,665 whitespace-delimited words and 32 references with 14,575 words; all were reachable within their packages. These are static observations, not tokens, actual loading costs, contradiction detection or evidence of behavioral equivalence. Remove needless ordinary-path hops; keep useful branch-only references and standalone safety.

## Candidate and limits

Select semantic pruning of existing owners, Doc/Review resource consolidation, stable-public-behavior tests and conditional evidence admission. Include the already inspected CLI argument and capsule-length redundancies and remove managed-prose spelling assertions without deleting preservation coverage.

No native Skill behavior or cost experiment was run. Offline checks and independent source review cannot establish native Skill behavior acceptance, causality or efficiency gains.
