## Bounded offline coverage

The existing seven-failure/five-successor corpus remains unchanged. Its five
JavaScript failures and two Python failures already cover these failure classes,
but it did not contain this new call chain or its String.raw successors.

The [offline regression][tests] now accepts only an exact String.raw tag with
a no-interpolation template and LF source text. It reads the raw literal bytes
from the AST without invoking the tag. Interpolated templates, arbitrary tags,
call expressions and CR/CRLF raw sources are rejected. The latter restriction
avoids claiming equivalence where JavaScript normalizes source line endings.

Both successful raw commands are compared with the independently retained native
CommandExecution command bytes. Additional controls preserve newline, backslash
and Unicode/hex escape text and compare it with JSON serialization as a
JavaScript argument. JSON serialization is not treated as shell escaping.

Validation compiles the JavaScript wrapper without running it, uses bash -n
without startup files, and compiles literal Python heredoc bodies without
executing them. It neither launches captured Git commands/workers nor mutates
the captured workspace. Syntax success and byte equality do not prove command
semantics, failure short-circuiting, safe replay, model reliability or cost savings.

string and failed with ReferenceError before parsing that control. Its retained

The correction constructs the interpolation as literal text. Final offline
