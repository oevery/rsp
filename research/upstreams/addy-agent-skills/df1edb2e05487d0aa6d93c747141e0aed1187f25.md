# Upstream Distillation: addy-agent-skills

## Source Position

- **Evidence:** The repository publishes 24 lifecycle and engineering Skills plus commands, host projections, structural validators, deterministic routing checks, and on-demand behavioral evals (`README.md`, `skills/**`, `evals/README.md`, `scripts/**`).
- **Inference:** Its broad lifecycle overlaps RSP, but its catalog-level routing evaluation is a distinct maintainer mechanism rather than another workflow model to import.

## Extracted Mechanisms

- **M1 — Three-tier evaluation:** structural checks validate metadata and parity; lexical routing tests cover positive, negative, pairwise-owner, rank, and description-collision cases; behavioral runs grade full execution or dialogue traces against expectations (`evals/README.md`, `scripts/run-evals.js`, `scripts/validate-skills.js`).
- **M2 — Restraint under pressure:** execution fixtures include time, sunk-cost, and authority pressure so a passing happy path cannot hide workflow abandonment (`evals/cases/**`, `evals/fixtures/**`).
- **M3 — Catalog routing is measured as a system:** positive prompts require top-k ownership, negatives can name the correct owner, and pairwise description similarity detects competing descriptions before model execution (`evals/README.md`).
- **M4 — Shared references create a portability hazard:** per-Skill installation can omit repository-level references, so a distributable Skill must be self-contained or package its dependencies explicitly (`README.md`, `AGENTS.md`).

## Applicable to RSP

- Add a deterministic catalog gate for realistic positive triggers, hard near-miss negatives, pairwise owner precedence, and description collisions.
- Keep behavioral evaluation artifact-aware: execution runs need real fixtures and full traces; conversational outputs need a separately justified dialogue kind.
- Add pressure prompts and correction/tool-call cost to promotion evidence for authority-sensitive RSP Skills.
- Validate that every published Skill remains self-contained when installed independently.

## Rejected

- Importing the 24-Skill lifecycle, slash-command layer, autonomous build mode, or shipping tail.
- Treating lexical TF-IDF rank as semantic proof; it is a cheap regression detector only.
- Making one global router mandatory before every task.
- Copying shared-reference layouts that break individual Skill installation.
