# Domain Modeling

Challenge terms against the existing project glossary, sharpen fuzzy language, discuss concrete edge cases, and cross-reference project facts. When the domain distinction remains an owner decision, propose precise canonical language and ask the user to settle it.

Do not modify `CONTEXT.md` or another domain owner until the user confirms the term. Do not invent a second glossary owner. This ordinary discipline has no RSP return-envelope contract.
