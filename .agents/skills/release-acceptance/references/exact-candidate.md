# Exact candidate

After the version and release surfaces are final, record the exact checkout and package identity and require the matching complete result under [local checks](deterministic-acceptance.md). Finalization alone requires no rerun when the existing result still applies; changed relevant inputs invalidate it. `prepublishOnly` runs the same thin aggregation; it neither starts models nor certifies Skill quality.

For changed Skill behavior, identify relevant fresh matrix results or explicitly report the missing behavioral evidence. Read `tests/skills/README.md`; never substitute historical campaign counts or rewrite retained verdicts. Independent review and publication remain separately authorized.
