# Agent-facing documents

Use for operating instructions and references an agent follows.

- **Expose the next decision.** Keep common constraints and needed local context visible. Each branch link names when to read and what information it supplies.
- **Keep related meaning together.** Place definitions, conditions and exceptions near the governed action; link one authoritative owner.
- **Make completion usable.** Include the action, prerequisites and recognizable result. Keep permissions beside the affected action and allow safe in-scope correction.
- **Prune unhelpful repetition.** Remove stale lookups and prose without decision value. Retain useful summaries, substantive qualifiers and local safety context; assumed model defaults are not proof of equivalence.
- **Check the reading path.** Inspect relevant targets and test the changed branch with a realistic task. Distinguish local reasoning from actual agent execution.

Do not add approval rounds, workers or document splits merely to regularize the prose. Retain background human co-readers need.
