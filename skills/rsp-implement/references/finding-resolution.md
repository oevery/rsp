# Bounded fixed-report finding resolution

Load only for one fixed read-only Review report and its original comparison or file set. Verify the selected Change, report identity (order, severity, title, location), current checkout, authority, and smallest affected behavior chain. A report grants investigation, never correction, fresh external checks, or Git authority. Preserve unrelated staged, modified, and untracked work.

Give every Finding one evidence-backed disposition: accepted when the issue and intended correction are confirmed inside the exact mutation boundary; rejected when direct evidence disproves it or authority does not require the suggestion; needs-clarification when intended behavior, reproducible trigger, owner, or safe scope is missing. Do not silently reinterpret, accept politely, or reject intuitively. One correction may address several accepted Findings while keeping their separate dispositions.

In one bounded pass fix only accepted Findings. Run fresh affected and declared checks after the last edit; failure, unavailability, stale evidence, or omission cannot close a Finding. Preserve the original report unchanged. Request a fresh fixed-scope, read-only rsp-review with original comparison, authority, post-fix paths, dispositions and evidence; the implementer cannot certify review-clean. Correlate its result on return. A further pass may continue only while original authority and scope still cover it and evidence improves, with a maximum of three finding-resolution passes and an earlier stop if the same Finding survives two corrections. Do not self-loop on repeated evidence. A material new requirement, changed scope, missing authority, or needs-clarification stops for the owner. Return dispositions, changed paths, checks, re-review status, unresolved Findings and next action; retain transient pass counts outside durable Change state.
