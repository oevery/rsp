# Local export contract

This Skill is intended only for explaining the local export invocation or preparing an export configuration when requested. An ordinary document edit or file search is not an export task.

The tool takes an explicit tenant and a new output path. Existing output must remain untouched. Missing tenant is a material input question; do not infer it from a username. The current task authorizes only Skill edits, not running exports. There is no remote service, deployment workflow or custom validation tool to add. Keep this small Skill self-contained.
