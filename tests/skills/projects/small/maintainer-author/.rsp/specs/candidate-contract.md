# RSP evidence-note candidate contract

This candidate summarizes already supplied verification evidence for one selected RSP Change. It does not execute checks or alter project state.

- Report a check as failed only when retained execution evidence shows failure.
- Missing, unavailable or unexecuted checks are unverified; preserve that distinction from actual failure.
- A passing subset does not close an omitted Required Verify item or establish independent acceptance.
- Retain the selected WorkRef, actual evidence boundaries and remaining gaps in the response.
- No test execution, filesystem mutation, Git delivery, lifecycle action, publication or independent approval is authorized by this candidate.
