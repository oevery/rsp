# Design

This miniature repository is an RSP-owned Skill candidate workspace. Authored candidate text lives under skills/; installed evaluation guidance under .agents/skills/ is separate and immutable.

The selected clarify-evidence-note Change owns one bounded revision under the candidate contract. Root AGENTS.md owns execution permissions and names the genuine isolated CLI and package checker under .tooling/rsp/. Tool availability does not grant candidate execution, independent approval, Git delivery or lifecycle authority.
