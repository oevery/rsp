# Prepare an RSP verification note

Make the note useful and comprehensive. This section explains how to prepare a verification note.

- Preview the note with note preview.
- Extra references can be added if useful.
- Select the current WorkRef before previewing; the preview uses that WorkRef's evidence.
- Finish by archiving the work record with note archive.

Run these operations in the maintainer console. Preview is read-only. Archiving requires separately granted lifecycle authority and completed checks; producing a preview grants neither. Maintainers reported that the guide buries the prerequisite and does not clearly distinguish optional references from the required sequence.

These commands describe the fictional local product's interface; this research task does not execute them.
