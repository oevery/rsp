## Complex environments

Commit cases combine owned staged work with unrelated unstaged and untracked content. Unrelated staged content must stop delivery, not be cleared or included. Wrong-result controls exercise wrong bytes, extra commits, index loss and missing verification. An exact case declaration is never a general Git permission.

Native checkout spans independent pricing and checkout owners, cross-module integer-money invariants, immutable checks, staged notes, an unrelated source edit and untracked scratch. A third worker verifies settled implementation. A blocked owner must not dispatch; an unavailable external acceptance fixture must stay incomplete. Host events establish identity and completion; role quality, ordering and command meaning require blind review.

## Acceptance limits

Run selected tasks serially, preserve failures, and stop on failure or incomplete execution. One independently reviewed candidate supports its selected task acceptance only; comparative or generalization claims need additional research design.

Native topology and child traces are not filesystem confinement or a cryptographic process audit. Untested combinations remain explicitly unverified. No baseline or private holdout is a mandatory daily/release gate.
