## 选择入口

- 第一次使用 RSP：从[五分钟入门](./getting-started.md)开始。
- 推进日常工作：使用[日常工作流](./guides/daily-workflow.md)。
- 选择 agent 能力：阅读 [Skills 与 managed work](./guides/skills.md)。
- 查询语法：打开 [CLI](./reference/cli.md) 或[配置](./reference/configuration.md)参考。
