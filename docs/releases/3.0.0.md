# RSP 3.0.0

RSP 3.0 establishes **Reliable Software Practice**, a repository-native engineering workflow for humans and AI agents. It combines nine independently invocable Skills with a lightweight Rules, Specs, Plans artifact foundation, stricter project-state safety, and durable ownership in ordinary project files.

## Highlights

- Model work with typed WorkRefs and shallow Change Groups. Groups declare direct children, share one completion contract, and preserve independent focus and archive behavior without recursive hierarchy or a persisted progress graph.
- Derive ready work, exact dependency edges, blockers, and stable execution waves directly from Change facts with `rsp status`.
- Route durable current facts, scoped instructions, and lasting rationale to separate owners, including one authoritative Decision Record directory.
- Use nine host-neutral Skills for Core workflow, Shape, Design, Implement, Diagnose, TDD, Review, Review Resolution, and Release Documentation.
- Fail closed on unsafe managed paths and invalid configuration, and generate Change templates that separate executable Tasks, verification coverage, current facts, and rationale.

## Breaking changes and migration

RSP 3.0 replaces `.rsp/rules/rsp-rules.md` with `.rsp/rsp-rules.md`, removes the project-rules command and templates, and rejects unsupported deep or ambiguous work paths. Projects upgrading from 2.x must run `rsp update` and review any residual custom `.rsp/rules/` content instead of deleting it blindly.

Follow the [RSP 3.0 migration guide](https://github.com/oevery/rsp/blob/v3.0.0/docs/migrations/3.0.md) before archiving or creating new work with the upgraded CLI.

## Package and compatibility

- The npm package contains the CLI, fallback protocol, and nine published Skills. Research, evaluations, self-hosting `.rsp/` state, maintainer scripts, caches, and the research-only `rsp-manage` candidate are excluded.
- The supported runtime remains Node.js 18 or later.
- On 2026-07-23, the exact `@oevery/rsp@3.0.0` tarball passed build, typecheck, lint, 352 automated tests, package inventory validation, clean installation, CLI discovery, and nine-Skill discovery. Clean installation was also exercised with Node.js 18.20.8.

## Known limitations

- Change Groups are intentionally one level deep.
- Managed orchestration is a host or external workflow, not a 3.0 product capability. The evaluated `rsp-manage` prototype remains research-only.
- RSP derives workflow guidance but does not grant mutation, Git, publication, deployment, environment, or human-approval authority.
- The verified `@oevery/rsp@3.0.0` tarball was not published to npm by maintainer decision. As verified on 2026-07-23, npm `latest` remains `2.0.4` and registry installation of `3.0.0` is unavailable.
