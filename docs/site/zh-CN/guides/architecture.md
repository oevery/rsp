# 阅读架构

项目可在 `.rsp/architecture.json` 维护与布局无关的架构模型。RSP 不自动发现代码、
也不生成该文件。未配置时明确提示，其他命令仍可使用。

## 定义模型

添加模型时，在根 `CONTEXT.md` 中登记一条导航；已有入口则复用。如果文件尚不存在，
在本次架构接入中创建最小入口。例如：

```md
架构导航见 [`.rsp/architecture.json`](.rsp/architecture.json)，包含模块关系及关联文档。
```

仅安装 RSP、尚无模型时不添加链接；普通安装和升级不会为此改写项目上下文。
模型描述保持简短并反映当前状态，详细契约留在关联文档中；尚未实现的架构留在
Change 的 Design 中。

```json
{
  "schemaVersion": 1,
  "nodes": [
    { "id": "app", "title": "应用", "description": "维护应用契约" },
    { "id": "api", "parent": "app", "title": "API", "description": "接收请求" },
    { "id": "store", "title": "存储", "description": "持久化记录" }
  ],
  "relations": [
    { "id": "writes", "source": "api", "target": "store", "type": "write", "description": "写入记录" }
  ],
  "views": [
    { "id": "application", "title": "应用边界", "node": "app", "include": ["api", "store"] }
  ],
  "bindings": [
    { "node": "app", "file": ".rsp/specs/application.md", "scope": "subtree" },
    { "node": "api", "file": ".rsp/specs/application.md", "headings": ["请求"] }
  ]
}
```

节点、关系、视图分别在各自集合中使用稳定 ID。节点 ID 不编码祖先，层级由 `parent`
表达。关系使用 `id`、`source`、`target`、`type`、`description`；视图用 `node` 表达
所属节点，`include` 明确列出节点。重复 ID、缺失引用、层级环和未知版本均明确失败。
标题、描述均为必填非空字符串。

绑定指向项目相对路径的 Markdown。省略 `headings` 表示整篇，章节绑定使用标题层级，
例如 `["API", "请求"]`。解析真实 Markdown 标题，不存行号；缺失或歧义会给出诊断。
`scope` 默认 `node`，仅显式 `subtree` 向后代继承，结果保留继承来源。
多个节点可共用一篇 Spec，节点也可没有文档。章节定位表达相关性，并不排除全文其他约束。
Specs 保留行为权威，Decisions 解释理由，CONTEXT 承载词汇与导航。

## 查询与打开

```sh
rsp architecture
rsp architecture --node api --json
rsp architecture --view application --json --compact
rsp doctor
rsp view
rsp view --no-open
rsp view status
rsp view stop
```

`architecture` 返回结构、视图、绑定原因、来源和诊断，不含文档正文。节点选择包括后代，
视图选择使用明确的节点列表；关联的外部端点标为边界，不继续扩展其邻居。两个选择器互斥。
文本与 JSON 一样保留父节点、关系 ID、视图所属节点，以及直接/继承绑定的作用域。
Web 中同名视图使用相同的精确选择并标记边界；父容器不会替代子节点成为关系端点。
完整查询没有数量截断；单个文件超过 16 MiB 会明确失败，不返回截断内容。
结构和普通命令均不启动服务、不加载布局运行时。

`doctor` 同时检查完整模型及其文档、章节绑定。模型未配置时不阻断；模型非法或绑定
无法解析时报告问题并使命令失败。使用 `doctor --json` 获取结构化结果。
检查通过不代表模型与实现的语义一致。

`view` 打开预构建的共享前端，`--no-open` 仅打印地址。每个项目或 Git 工作树应在自己的
目录中用其选定的 RSP 调用打开。菜单仅列出当前运行时显式打开过的工作区；各自隔离图、
正文、修订与导航。

已注册的 Git 工作区按仓库分组，显示分支或分离 HEAD 的提交、主工作树或关联工作树身份，
并保留路径供区分。无法读取 Git 元数据时退回目录名称，不自动发现或注册其他工作树。

## 浏览架构图

左侧常驻工作区选择、对象搜索和全部声明视图。打开时进入按编写顺序排列的第一个视图；
没有声明视图时直接显示完整注册结构。点击侧栏切换视图，当前项高亮，导航不会消失。
不必经过卡片首页，也不新增默认视图配置；深链接仍直接进入指定视图或关系聚焦。
视图成员只表达阅读范围，不改变结构归属；共享包可在多个视图
中复用同一身份，不必增加统一的产品、平台层级。
搜索时用 Up/Down、Home/End 选择结果，按 Enter 只查看信息、不切换视图；
Escape 清除当前搜索。
紧凑项目选择器位于侧栏顶部。长工作区名称省略显示，箭头位置固定；聚焦或悬停可查看全名。

通过 **界面语言** 切换 **简体中文** 和 **English**。首次使用时，浏览器首选语言以 `zh`
开头则使用 `zh-CN`，其他语言使用英文；手动选择仅由浏览器为当前本地查看器来源记忆，
不写项目或全局配置。下文以简体中文宿主界面为例。作者写入的对象、视图、工作区名称、
职责、关系类型、Spec 内容、路径和代码保持原文；边界、引用标记及宿主状态会翻译，
技术诊断则在折叠的详情中保留真实原文。

LikeC4 1.60.0 没有公开翻译入口。其原生 **Browse … relationships**、**Relationships of**、
**Scope**、**Global**、**Current view**、关系地址控件和图键盘说明仍为英文。
RSP 不私改或移除这些能力；语言切换覆盖 RSP 宿主，不代表原生图的每个字符串都已双语化。

点击对象打开紧凑信息卡，显示职责、结构父级和相关视图、文档，不切换视图或改变平移、
缩放，也不常驻占用详情列。没有绑定文档时不显示空“关联文档”区域；展开
**关联关系** 可读精确关联列表。
**内部视图** 显式进入对象拥有的视图；多个视图可选，没有视图时不显示此入口。
**聚焦关联关系** 只显示对象的直接关联关系及真实端点，不像 CLI `--node` 那样
扩展后代。聚焦图平铺这些端点，不加入未选中的祖先容器；模型中的结构父级不变，仍可在
详情查看。局部结构视图保留真实层级。关系保留项目写明的类型，包括生命周期、重试；
箭头不表示执行顺序。
外部端点除了样式，还带有边界文字标识。
当前对象已处于关系聚焦时，信息卡不重复显示聚焦动作。

点击连线或关系列表项可查看精确的起点、终点、类型和描述，不自动聚合关系。
无法绘制的关系会显示 **关系未绘制** 提示，并可进入精确详情。
原生关系浏览和平移、缩放仍可使用。紧凑横向图使用项目写明的关系类型作为短标签，
完整描述留在信息卡中。

在结构视图中，LikeC4 不能直接绘制自环或祖先/后代关系，展开的容器也可能抑制自身关系。因此这些
目标及参与关系的容器端点使用明确标注的引用节点（relationship reference），普通叶节点
端点和可见层级不变。选择引用仍打开原节点的绑定和视图选择，不新增架构身份；引用节点
提供详情和原生关系浏览；指向引用的边不等于图形自环，各条关系不会被静默合并或丢弃。
折叠的 **来源与诊断** 区域提供来源身份、引用说明与模型诊断。

## 阅读 Spec

点击文档链接，在独立右侧阅读抽屉中按需加载完整 Markdown；绑定章节存在时定位到该章。
阅读时隐藏信息卡，不让两个详情层抢空间。**本页目录** 提供章节目录。
拖动抽屉左侧分隔线可调宽；分隔线获得焦点后也支持方向键 Left/Right。
**展开阅读** 展开到画布全宽，左侧导航仍保留。
**返回架构图** 关闭抽屉，恢复原对象信息卡。抽屉打开、调宽、展开和关闭均不重新布局、
自动适配或改变图的平移、缩放。
长文档路径优先省略，不挤占展开、返回操作；聚焦或悬停路径可读全名。
桌面阅读为非模态：不加遮罩、不限制焦点，未被覆盖的画布及平移、缩放控件仍可使用。
Escape 只关闭最上层；关闭阅读后，原对象仍可见时将键盘焦点还给该对象。
阅读期间保留原选择；需先关闭阅读，再选择其他对象或打开原生关系浏览。

浏览器默认字号下，Spec 正文、代码和表格统一使用 14px，配合紧凑间距和受限正文行宽。
长代码、宽表格通过横向滚动查看，不缩小文字；表格保留表头和声明的列对齐。
桌面与窄屏切换会保留当前阅读位置，无论最初通过章节还是整篇文档入口打开。

## 窄屏与状态恢复

窄屏通过 **导航** 打开项目、搜索和视图导航抽屉，文档使用独立全宽阅读区，
不压缩成三栏。
这些窄屏抽屉在关闭前约束键盘焦点。Escape 先清除搜索，再关闭导航抽屉并将焦点还给
**导航**；选择搜索结果时则将焦点移至对象信息卡。
深链接、刷新和返回会恢复有效的视图、关系聚焦与选择；同一阅读会话内返回，还会恢复同一
工作区、图修订下的平移和缩放。视图或聚焦对象删除后明确回退到完整结构，已选对象删除
则显示不可用提示；不跨浏览器会话持久保存视口或布局历史。

## 内容访问与安全

绑定的 Markdown 是阅读入口；其中的相对 Markdown 链接和 PNG/JPEG/GIF/WebP 图片可以
到达项目内的兄弟目录，例如 `docs/specs/api.md` 可引用 `../images/a.png`。链接文档可
继续引用其他文档，循环会终止。无法从绑定到达的文件不能读取，即使同目录已有可读文件；
删除链接后，下一次读取即撤销相应访问。每次授权最多检查 16 MiB Markdown，超限明确失败。

拒绝符号链接、路径穿越、运行时目录、隐藏路径，以及以 secrets、credentials、private
等名称标识的敏感路径；隐藏路径仅对 `.rsp/specs/` 和显式绑定的 `.rsp/` 文档目录例外。
被拒链接会标记不可用；本地文档链接仅支持 Markdown。
不执行原始 HTML、MDX 或项目脚本，不加载外部图片；普通 HTTP/HTTPS 和邮件链接保留。
HTTP/HTTPS 链接无论采用内联还是引用式 Markdown，都打开新标签页；本地文档链接继续使用阅读器。
请勿绑定不希望本地阅读会话访问的私有文档。打开地址携带当前运行时已注册工作区的本地
只读凭据，应保密。

## 刷新与服务生命周期

活动页面每五秒及重新激活时检查来源。仅正文变化会复用图布局，并保留有效阅读位置。
失败时明确标记旧内容过期，修复后可恢复。修订覆盖未提交文件、配置与架构，不只使用
Git HEAD。实现采用轮询，不持有文件系统 watcher。

后台服务仅监听 `127.0.0.1`，自动选择端口。`~/.cache/rsp/viewer/` 中只保存仅当前用户
可读的运行时与凭据发现记录，不保存模型或正文。并发打开复用兼容服务；包版本、真实安装
路径和构建身份共同决定运行时，不同身份自动隔离，源码重建也会使用新服务。
不替换项目运行时、不升级、不另装查看器，不生成 `.c4`、构建项目网站或运行时下载。
同包附带查看器依赖和前端资源，因此安装体积增加。

页面每 20 秒发送有效心跳，后台标签页仍保持阅读会话。连续 30 分钟没有有效心跳时退出；
工作区闲置五分钟后释放模型和布局，重新打开时从来源恢复。浏览器长时间挂起可能断线，
此时重新运行 `rsp view`。`view status` 仅显示当前运行时，`view stop` 断开该运行时的
全部工作区并释放端口；关闭启动命令所在终端不会停止阅读。
