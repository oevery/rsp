# Change Group: skill-context-optimization

## Goal
- Reduce the default Skill suite's routinely loaded context and wording-change amplification without weakening routing, authority, stop, verification, review, lifecycle, or delivery behavior.

## Scope
- Replace broad prose-presence assertions with focused structural and behavioral contracts where equivalent evidence exists.
- Introduce progressive disclosure for inactive Manage and Review branches.
- Compress the Core routing surface after the supporting contracts and branch ownership are stable.
- Retain symbolic notation only where a measured closed flow benefits from it.

## Shared Constraints
- Preserve the runtime roles, invocation modes, and published Skill inventory.
- Keep every Discipline independently invocable and keep detailed procedures inside the owning Skill package.
- Preserve exact canonical enums, authority denials, stop/resume rules, acceptance gates, and closeout boundaries.
- Do not introduce a runtime glossary, private DSL, persisted controller state, or recursive Skill loading.
- Evaluate loaded-path size and behavior after each child; token reduction alone never proves equivalence.

## Slices
- `skill-context-optimization/semantic-contract-tests`: reduce wording-coupled Skill assertions while preserving structural and behavioral evidence.
- `skill-context-optimization/manage-progressive-disclosure`: conditionally load inactive interruption, review-convergence, and closeout procedures from `rsp-manage`.
- `skill-context-optimization/review-progressive-disclosure`: conditionally load Code and Document review pipelines after scope classification.
- `skill-context-optimization/core-routing-compression`: compress the eager Core route kernel and retain only measured, self-explanatory notation.

## Completion Conditions
- [x] Every child passes its focused contract tests and the package build, lint, and full serial test suite pass.
- [x] Common direct, managed, review, and unavailable-capability paths retain their authority and stop behavior.
- [x] The final measured routinely loaded Skill paths are smaller than the starting corpus without relying on glossary-dependent symbols.
- [x] The fixed-scope final review has no unresolved accepted finding.

## Durable Outcomes
- Current facts: updated `skill-system.md` for the stable semantic-contract and progressive-disclosure behavior.
- Lasting rationale: no Decision Record was required because implementation introduced no new material tradeoff outside the Skill System.
- Review: the fixed-scope final Code and Document review is clean with the semantic matcher finding resolved.
