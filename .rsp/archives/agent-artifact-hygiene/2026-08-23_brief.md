# Change Group: agent-artifact-hygiene

## Goal
- Improve the behavior of agents using installed RSP in downstream repositories so final artifacts do not preserve session-only rejected alternatives and permanent tests are retained only for independent production confidence.

## Scope
- Distill the bounded final-output hygiene mechanisms in `LB623/no-negative-echo` with pinned provenance and license evidence.
- Add the smallest RSP-owned finalization behavior needed for session-residue control, with current-versus-candidate evidence.
- Strengthen real-project-derived evaluation of downstream test selection and revise published Skills only when current behavior fails a fixed acceptance contract.

## Shared Constraints
- Keep final-output residue and low-value test selection as separate behavior owners with shared evaluation principles; do not publish a universal cleanup Skill.
- Preserve truthful migration, safety, compatibility, audit, deletion, failure, and external-action facts even when they contain negative information.
- Do not optimize for fewer tests alone; retain tests that protect independent observable consequences or real production boundaries.
- Treat upstream mechanisms as research options until a selected Change cites a completed report recommendation and adoption mode.
- Use independently reimplemented downstream fixtures; do not copy proprietary project code or retain credentials, provider identifiers, or raw session traces.

## Slices
- `agent-artifact-hygiene/distill-no-negative-echo`: Produce a complete pinned upstream report with bounded recommendations for RSP finalization surfaces.
- `agent-artifact-hygiene/final-output-residue`: Evaluate and implement the selected final-surface residue mechanism in existing RSP owners without creating a general cleanup workflow.
- `agent-artifact-hygiene/downstream-test-value`: Add realistic downstream test-selection holdouts and revise implementation, TDD, or review contracts only when fixed comparison evidence identifies a remaining gap.

## Completion Conditions
- [x] The upstream report distinguishes negative-echo control from implementation restraint and records license, provenance, rejected mechanisms, and stable recommendation IDs.
- [x] Finalization behavior passes deterministic contracts and frozen unseen current-versus-candidate cases while preserving required negative facts.
