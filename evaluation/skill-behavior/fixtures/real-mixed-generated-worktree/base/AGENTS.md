# Project Rules

- Files under `src/generated/` are generated; review their public contract but do not request hand edits or report formatting noise.
- Data-plane transports receive only explicitly projected public upload fields.
- Relevant untracked production files are part of an all-worktree review.
- `.agents/skills/local-notes/` and `tools/local-review/` are local reviewer aids, not product code or product authority.
